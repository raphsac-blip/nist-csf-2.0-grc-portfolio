# Cybersecurity GRC Portfolio — NIST CSF 2.0

## Project Overview

This project demonstrates practical cybersecurity
governance, risk management, and compliance (GRC)
skills through a simulated organizational risk
assessment using the NIST Cybersecurity Framework
(CSF) 2.0.

## Project Objectives

- Identify and assess organizational cybersecurity risks.
- Evaluate security controls against NIST CSF 2.0.
- Develop a cybersecurity risk register.
- Recommend risk mitigation strategies.
- Develop security policies and compliance documentation.

## NIST CSF 2.0 Functions

1. Govern (GV)
2. Identify (ID)
3. Protect (PR)
4. Detect (DE)
5. Respond (RS)
6. Recover (RC)

## Planned Deliverables

- Organizational cybersecurity assessment
- Cybersecurity risk register
- Security controls assessment
- Sample information security policy
- Executive risk remediation report

## Disclaimer

This is an educational portfolio project using a
fictional organization and simulated data. No real
organizational or confidential information is used.
