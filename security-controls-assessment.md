# Security Controls Assessment

## Maryknoll Sisters — Independent Educational Simulation

Framework: NIST CSF 2.0

### Control Assessment 001

**Risk ID:** R-003

**Threat:** Business Email Compromise (BEC)

**Risk Score:** 20/25 — Critical

**NIST CSF 2.0 Mapping:** PR.AA-05 — Access permissions, entitlements, and authorizations are defined in a policy, managed, enforced, and reviewed.

**Recommended Controls:**
- Require multifactor authentication for financial system access.
- Restrict financial approval permissions to authorized personnel.
- Independently verify changes to payment instructions using a trusted phone number.

**Control Implementation Status:** Not assessed — hypothetical scenario.

**Suggested Evidence:** Access review records, MFA configuration reports, and payment verification procedures.

**Disclaimer:** This is an independent educational simulation. No actual Maryknoll Sisters systems, controls, or vulnerabilities were examined.

**Threat:** Phishing

**Risk Score:** 16/25 — High

### Control Assessment 004

**Risk ID:** R-004

**Threat:** Ransomware

**Risk Score:** 12/25 — Medium

**NIST CSF 2.0 Mapping:**
- PR.PS-02 — Software is maintained, replaced, and removed commensurate with risk.
- PR.PS-05 — Installation and execution of unauthorized software are prevented.
- DE.CM-09 — Computing hardware, software, runtime environments, and their data are monitored to find potentially adverse events.

**Recommended Controls:**

### Control Assessment 005

**Risk ID:** R-005

**Threat:** Data Loss / Backup Failure

**Risk Score:** 15/25 — High

**NIST CSF 2.0 Mapping:**
- PR.DS-11 — Backups of data are created, protected, maintained, and tested.
- RC.RP-03 — The integrity of backups and other restoration assets is verified before using them for restoration.

**Recommended Controls:**
- Implement regular, encrypted backups of critical organizational data, including protected offline or immutable copies.
- Conduct periodic backup restoration tests to verify data recovery capabilities.
- Verify backup integrity before restoring organizational systems.

**Control Implementation Status:** Not assessed — hypothetical scenario.

**Suggested Evidence:** Backup schedules, backup job reports, restoration test results, backup integrity verification records, and documented recovery procedures.

**Disclaimer:** All controls, vulnerabilities, and risks are hypothetical. No actual Maryknoll Sisters systems or backup infrastructure were assessed.
