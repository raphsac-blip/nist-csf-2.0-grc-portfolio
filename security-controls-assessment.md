# Security Controls Assessment

## Maryknoll Sisters — Independent Educational Simulation

Framework: NIST CSF 2.0

### Control Assessment 001

**Risk ID:** R-003

**Threat:** Business Email Compromise (BEC)

**Risk Score:** 20/25 — Critical

**NIST CSF 2.0 Mapping:** PR.AA-05 — Access permissions, entitlements, and authorizations are defined in a policy, managed, enforced, and reviewed.

**Recommended Controls:**
- Require multifactor authentication for financial system access.
- Restrict financial approval permissions to authorized personnel.
- Independently verify changes to payment instructions using a trusted phone number.

**Control Implementation Status:** Not assessed — hypothetical scenario.

**Suggested Evidence:** Access review records, MFA configuration reports, and payment verification procedures.

**Disclaimer:** This is an independent educational simulation. No actual Maryknoll Sisters systems, controls, or vulnerabilities were examined.
